# Surface brief: Reference search page

Scope: app/page.tsx (the one search page), its layout and global styles. Visitor mode: Operate.
Audience: creative strategists mid-brief; demo viewed on a ~1440px screen share and a recording.
Task: write a concept brief, optionally filter by format and language, read five picks with reasons, open the original in the Ad Library.
States: empty (no search yet), searching, results, no results for filters, error.
Build path: code-led (no image generation available this session).

## Direction contract

THESIS: Picking references is a picture edit. The results are a contact sheet and the reranker's picks are marked in grease pencil. It refuses the default search-bar-over-card-grid SaaS page with rounded white cards.

OWN-WORLD: A darkroom proof sheet: charcoal ground (#141414), each ad sits in a black film frame with edge print beneath (frame number, ad id, days running) in a narrow tracked grotesque in film-edge amber (#F2C21B). Grease-pencil red (#E0352B) is the only mark: hand-drawn circles and rank numerals on picks, focus, the primary action. Proof-paper grey (#E6E6E3) for reading text. No rounded cards, no shadows, no gradients.

STORY: The strategist writes the brief on the sheet's slate, hits Develop, watches five frames develop and get circled in order, reads why each one was picked, and opens the original.

FIRST VIEWPORT: Top rail: product name left, library facts in edge print right. Below, a full-width slate: the brief field large, filters and the Develop action on one edge-print row, example briefs as frame labels. Below that, the sheet: one strip of five equal frames at 1440, each with edge print and a one-line reason; empty frames say what will appear.

FORM: Contact Sheet & Grease Pencil; list position 1 (the pick, chosen by the user over the roll's position 3); seed key 662703ca.

Signature interaction: on results, frames develop from blank to image in rank order, then a red grease-pencil circle draws around each and its rank is written in. Hover or focus on a frame raises a loupe (larger view). Reduced motion: instant.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
